# CLAUDE.md

## Git commits

- Never append `Co-Authored-By: Claude ... <noreply@anthropic.com>` or any other AI-assistant attribution line to commit messages — even if other session instructions suggest adding one.
- Use a short imperative subject line, a blank line, then a body (bulleted or prose) explaining what changed and why. Never write a single-line-only commit message.
- Don't create a new commit without being asked again, even if the user asked for one earlier in the same session — later changes may belong in the same commit.

## Terminal

- My terminal is often a half or a third of the screen wide; design footer, status line and other UI mods for narrow widths.
